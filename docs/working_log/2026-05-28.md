# Working log — 28 May 2026

**Workstream**: B (ship observations data)
**Hours allocated**: approximately 4.0

## Task description

1. Established a reusable THREDDS catalogue-crawling method for bulk retrieval of IMOS SOOP datasets from the AODN THREDDS server (https://thredds.aodn.org.au), replacing the manual file-by-file download that the THREDDS HTML interface otherwise requires. The method fetches the machine-readable catalog.xml form of each directory, extracts downloadable file urlPaths, constructs fileServer download URLs, writes them to a project-convention manifest, and retrieves them via wget with resume, retry, timeout, and no-clobber flags.
2. Applied the method to the SOOP-ASF (Air-Sea Flux) sub-facility for both vessels across both products (flux_product and meteorological_sst_observations), discovering year subdirectories automatically via catalogRef references and producing four vessel-product manifests covering RSV Nuyina (2023 onward) and Aurora Australis (full operational span).
3. Applied the method to the SOOP-BA (Bioacoustics) sub-facility, confirming it holds a single Aurora Australis voyage (April 2012), identical to the file previously retrieved from the old AODN portal on 14 May; recorded as a verified-identical holding rather than net new coverage.
4. Extended the method to a fully recursive catalogue descent to handle the deeper SOOP-CO2 hierarchy (vessel / year / voyage / files), retrieving the Aurora Australis surface-ocean carbon-dioxide product across 2011 to 2020. This product is the authoritative source for the pCO2 priority variable Patricia added at the 19 May meeting.
5. Completed retrieval of all products available for Aurora Australis and Nuyina through the IMOS THREDDS server, organising each sub-facility/product/vessel combination into its own dated download directory under data/raw/ship/aodn_downloads/ following the established project naming convention.
