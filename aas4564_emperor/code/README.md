# AAS 4564 Emperor penguin colony observations

Combines the 27 per-colony sheets of Barbara Wienecke's satellite-imagery log
(2018-2025) into one long-format CSV, with a QC log of every correction.

Usage:
    python combine_emp_colony_sheets.py "<workbook>.xlsx" <output_dir>/

Requires pandas and openpyxl. Data are not stored in this repository.
